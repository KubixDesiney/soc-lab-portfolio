# Portfolio presentation checklist

For an interview or recruiter review, lead with:

1. The architecture diagram and the data path from endpoint or application to Wazuh and Splunk.
2. One PowerShell detection case showing validation, correlation, and disposition.
3. One application telemetry case showing producer time versus ingestion time.
4. One false-positive tuning case showing why the condition was narrowed.
5. A screenshot of the local dashboard with identifiers and URLs redacted.

Describe the lab as a controlled learning environment. Do not claim that synthetic events are production incidents.
